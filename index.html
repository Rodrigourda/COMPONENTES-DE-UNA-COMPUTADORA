LOS COMPONENTES DEL ORDENADOR

Descubre las partes que hacen funcionar un ordenador

Hardware Componentes Software

¿Qué es el hardware?

El hardware es el conjunto de componentes físicos de un ordenador. Son todas las partes que podemos tocar, como el teclado, el ratón o la pantalla.

Componentes principales

1. Procesador (CPU)

Es el cerebro del ordenador. Se encarga de procesar la información y ejecutar las instrucciones.

2. Memoria RAM

Almacena temporalmente los datos de los programas que estamos utilizando.

3. Disco duro o SSD

Sirve para guardar archivos, fotografías, documentos y programas.

4. Placa base

Es la placa principal donde se conectan todos los componentes del ordenador.

5. Tarjeta gráfica (GPU)

Se encarga de procesar las imágenes y los gráficos que aparecen en la pantalla.

6. Fuente de alimentación

Proporciona la energía eléctrica necesaria para que funcionen los componentes.

7. Monitor

Es la pantalla donde podemos ver la información del ordenador.

8. Teclado y ratón

Son dispositivos que permiten introducir información y controlar el ordenador.

¿Qué es el software?

El software es el conjunto de programas y aplicaciones que permiten que el ordenador funcione. Algunos ejemplos son Windows, Google Chrome y los videojuegos.
